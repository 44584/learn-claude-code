这一节讲错误处理与恢复

三种常见错误:

- 输出被截断(模型话说一半 token 用完了)
- 上下文过长
- 临时故障(429限流, 529过载)

解决

| 模式       | 触发              | 恢复动作                                 |
| ---------- | ----------------- | ---------------------------------------- |
| 输出截断   | `max_tokens`      | 升级 8K→64K / 续写提示                   |
| 上下文超限 | `prompt_too_long` | reactive compact → 重试                  |
| 临时故障   | 429 / 529         | 指数退避 + 抖动，连续 529 可切换备用模型 |
